# Такт — план привычек для e-ink

Одностраничный локальный планер привычек под 6" e-ink планшет. Крупные плитки
без прокрутки, отметка одним касанием, просрочка остаётся на экране, пока её не
закроют. Ни сети, ни аккаунтов, ни аналитики: данные живут в браузере устройства.

**Живая версия:** https://danilka88.github.io/eink-planner/

![Доска](design/screens/eink-536-day.png)

## Что умеет

- **Доска дня.** 1–4 колонки, плитки занимают всю площадь, читаются с 1–2 м.
- **Привычка в своём окне.** Появляется в `06:30`, после `09:30` становится
  «просрочено · до 09:30» и висит, пока её не отметят (можно отключить).
- **Одно касание** — выполнено: плитка инвертируется, через 5–60 минут исчезает.
- **Повтор:** каждый день, по дням недели, каждое N-е число, разово на дату.
- **История и архив.** Все отметки по дням, снятие и возврат; выключенные
  привычки не теряют историю.
- **Копирование** привычки в один тап.
- **Долги** за прошлые дни, закрываются задним числом.
- **8 языков** (RU, EN, ES, PT, FR, ZH, HI, AR), формат времени 12/24,
  тема светлая/тёмная/авто, экспорт и импорт JSON.
- **Офлайн:** service worker, PWA-манифест, ни одного сетевого запроса.

## Быстрый старт

```bash
git clone https://github.com/Danilka88/eink-planner.git
cd eink-planner
python3 -m http.server 8080
```

Открыть `http://127.0.0.1:8080`.

> Открывать `index.html` двойным щелчком нельзя: используются ES-модули, браузер
> блокирует их на `file://`.

### Установка на планшет

1. Откройте сайт по **https** (или `localhost`) — только там работает
   офлайн-кэш.
2. Меню браузера → «Добавить на главный экран».
3. Включите авиарежим и откройте ярлык: приложение работает без сети.

По обычному `http://192.168.x.x` офлайн-режим недоступен — это ограничение
браузеров, а не приложения. В настройках есть блок «О приложении», который
показывает текущее состояние.

## Управление

| Действие | Что делает |
|---|---|
| Касание плитки | отметить / снять отметку |
| Долгое нажатие | редактор привычки |
| Долгое нажатие на просроченной | записать пропуск |
| «Все» → «Привычки» | вкл/выкл, копировать, изменить, добавить |
| «Все» → «История» | отметки по дням: снять, отметить, пропустить, вернуть |
| «Все» → «Архив» | вернуть привычку или удалить навсегда |
| «Обновить» | полная вспышка экрана (очистка ghosting) |
| «Настройки» | тема, язык, таймеры, демо, экспорт/импорт, сброс |

## Приватность

Ни одного сетевого запроса: `connect-src 'none'` в CSP запрещает их на уровне
браузера. Данные лежат в `localStorage` и никуда не уходят. Подробнее —
`PRIVACY.md`.

## Данные

- Всё хранится в `localStorage` браузера на устройстве. Синхронизации нет.
- **«Поделиться»** — системное меню Android: файл сразу уходит в Telegram, почту или «Файлы».
- **«Экспорт в файл»** — скачивание `takt-YYYY-MM-DD.json`.
- **«Импорт из файла»** заменяет всё содержимое после подтверждения.
- Очистка данных сайта удаляет привычки: экспорт — единственная страховка.
- Адрес = хранилище. После смены адреса данные переносятся экспортом и импортом.
