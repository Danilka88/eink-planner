# Как участвовать

## Запуск

```bash
python3 -m http.server 8080
```

Открыть `http://127.0.0.1:8080`. Открывать `index.html` двойным щелчком нельзя:
используются ES-модули, браузер заблокирует их на `file://`.

## Тесты

```bash
npm test
```

Тесты обязаны проходить до пул-реквеста. Новая логика расписания — новый тест в
`tests/schedule.test.js`.

## Стиль

- Ванильный JS, без фреймворков и сборщика.
- Логика, которую можно протестировать, — в `js/core/`, без обращения к DOM.
- Никаких сетевых запросов: CSP это запрещает, и это принцип проекта.
- Строки интерфейса — только через `t("key")` и оба словаря.
- Иконки — из Phosphor Bold, вшитые в `js/core/icons.js`.

## Что проверить перед PR

1. `npm test` — зелено.
2. Приложение работает на 536×724 и 375×812, без прокрутки доски.
3. Тёмная и светлая темы, оба языка.
4. `errors 0`, `axe 0` в аудите дизайна (см. `docs/TESTING.md`).
