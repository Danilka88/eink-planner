# Модель данных

Всё лежит в `localStorage` под ключом `ritual.v1`. Резервная копия демо-режима —
`ritual.backup`.

## Схема (версия 2)

```jsonc
{
  "version": 2,
  "items": [
    {
      "id": "itm_teeth_am",
      "title": "Зубы утром",
      "icon": "teeth",              // ключ из HABIT_ICONS
      "start": "06:30",             // окно появления
      "end": "09:30",               // окно скрытия (может быть меньше start — через полночь)
      "repeat": "daily",            // daily | weekly | monthly | once
      "days": [0,1,2,3,4,5,6],      // для weekly
      "monthDay": 1,                // для monthly, 1..31
      "date": "2026-11-10",         // для once
      "keepOverdue": true,          // не убирать с экрана, пока не выполнено
      "archived": false,            // выключена (в архиве)
      "deleted": false,             // мягко удалена
      "order": 0,
      "createdAt": "2026-11-10T05:00:00.000Z"
    }
  ],
  "log": {
    "2026-11-10": {
      "itm_teeth_am": { "s": "done", "t": "2026-11-10T05:10:00.000Z", "late": false }
    }
  },
  "settings": {
    "theme": "auto",        // auto | light | dark
    "eink": true,
    "hideDoneMin": 20,      // 0 = скрывать сразу
    "debtDays": 3,          // 0..14
    "refreshMin": 30,       // 0 = выключено
    "keepAwake": false,
    "lang": "auto"          // auto | ru | en
  },
  "meta": { "createdAt": "...", "firstRun": false }
}
```

## Ключевые решения

- **Лог по датам, а не по привычкам.** `log["2026-11-10"]["itm_x"]` — отметка
  принадлежит дню. Поэтому «каждый день» автоматически начинается заново.
- **Пропуск — это запись, отсутствие записи — это «не отмечено».** `s: "skip"`
  убирает плитку с доски, но остаётся в истории.
- **`late: true`** — отметка задним числом (из долгов или истории).
- **Удаление мягкое.** `archived: true` убирает привычку с доски, `deleted: true`
  дополнительно скрывает из архива. Полное удаление чистит и `log`.

## Миграции

`normalize()` приводит любые входные данные к версии 2:

| Было | Стало |
|---|---|
| нет `repeat`, `days.length === 7` | `repeat: "daily"` |
| нет `repeat`, `days` частичный | `repeat: "weekly"` |
| нет `keepOverdue` | `true` |
| нет `lang` | `"auto"` |
| нет `deleted` | `false` |

Миграция выполняется при каждом `load()`, и если версия в файле отличается от
текущей — результат сразу записывается обратно.

## Импорт

`Импорт из файла` заменяет состояние целиком после подтверждения. Данные
проходят тот же `normalize()`, поэтому старый файл (версия 1) тоже подойдёт.
