# Публикация на GitHub Pages

Приложение статическое: сборка не нужна, деплой — это `git push`.

## Первый раз

```bash
cd eink-planner
git init -b main
git add .
git commit -m "Takt 1.4.0"
gh repo create eink-planner --public --source=. --remote=origin --push
gh api -X POST "repos/Danilka88/eink-planner/pages" \
  -f "source[branch]=main" -f "source[path]=/"
```

Через минуту сайт откроется на `https://danilka88.github.io/eink-planner/`.

## Обновление

```bash
git add .
git commit -m "что изменилось"
git push
```

Pages пересоберёт сам. Если поменяли файлы оболочки — **поднимите версию кэша**
в `sw.js` (`const CACHE = "ritual-shell-vX.Y"`), иначе планшет останется на
старой версии.

## Что важно знать

- **`.nojekyll`** обязателен: иначе GitHub выбрасывает файлы, начинающиеся с
  подчёркивания, и ломает отдачу.
- **Заголовки HTTP на Pages не настроить.** Поэтому CSP живёт в `<meta>` внутри
  `index.html`, а не в `_headers`.
- **Адрес = хранилище.** Данные привязаны к origin. После переезда со старого
  адреса перенесите их: Настройки → Экспорт на старом → Импорт на новом.
- **Индексация включена** (`index, follow`), есть `robots.txt`, `sitemap.xml`,
  OG-карточка `icons/og.png` 1200×630 и JSON-LD `SoftwareApplication`.
- **Язык** переключается на клиенте, отдельного URL на язык нет, поэтому
  hreflang не используется.

## Проверка после деплоя

1. Открыть адрес, убедиться, что версия в настройках — актуальная.
2. Меню Chrome → «Добавить на главный экран».
3. Включить авиарежим, открыть с ярлыка — приложение должно работать.
4. В настройках блок «Офлайн-режим» должен показывать «работает».
