# Локализация

Сейчас: **русский** и **английский**. Выбор — в настройках: «Авто» (язык
устройства), «Русский», «English».

## Как устроено

- Словари лежат прямо в `js/core/i18n.js` объектами `DICT.ru` и `DICT.en`.
  Это модуль, а не JSON: `fetch` запрещён политикой CSP.
- `t(key, vars)` подставляет `{name}` и выбирает форму склонения.
- Даты и дни недели — через `Intl.DateTimeFormat`, а не таблицами строк.
- `setLocale()` переключает `<html lang>`; `document.title` и
  `<meta name="description">` обновляются в `applyLanguage()`.

## Добавить язык

1. Скопируйте блок `ru` в `DICT` и переведите значения.
2. Добавьте код в `LOCALES` и в `settings.lang` (список допустимых значений —
   в `normalize()` в `js/core/state.js`).
3. Добавьте кнопку в `renderSettings()` (секция «Язык»).
4. Запустите `npm test` — тест сверяет набор ключей между словарями и упадёт,
   если чего-то не хватает.

## Склонения

Ключ-объект выбирает форму через `Intl.PluralRules`:

```js
"tile.daysAgo": { one: "{n} день назад", few: "{n} дня назад", many: "{n} дней назад" }
```

Для английского достаточно `one` и `other`. Если формы нет — берётся `other`.

## Что не переводится

- **Названия привычек пользователя.** Это данные, а не интерфейс.
- **Стартовый набор** переводится только при первом запуске — у нового
  пользователя привычки создаются на его языке.

## Ограничения

Язык переключается на клиенте, отдельного URL на язык нет. Поэтому hreflang не
используется: для поисковика страница одна, а `lang` меняется скриптом.
