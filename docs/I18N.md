# Локализация

Сейчас: **8 языков**. Выбор — в настройках: «Авто» (язык устройства) или
конкретный язык. Для арабского включается направление справа налево.

| Код | Язык | Направление |
|---|---|---|
| `ru` | Русский | LTR |
| `en` | English | LTR |
| `es` | Español | LTR |
| `pt` | Português | LTR |
| `fr` | Français | LTR |
| `zh` | 中文 | LTR |
| `hi` | हिन्दी | LTR |
| `ar` | العربية | **RTL** |

## Как устроено

- Словари — отдельные модули в `js/core/dict/<код>.js`, по одному объекту на
  язык. Это модули, а не JSON: `fetch` запрещён политикой CSP.
- `js/core/i18n.js` собирает их в `DICT`, отдаёт `t(key, vars)` и управляет
  локалью.
- `t(key, vars)` подставляет `{name}` и выбирает форму склонения.
- Даты, дни недели и время — через `Intl`, а не таблицами строк.
- `setLocale(code, timeFormat)` переключает `<html lang>`, `<html dir>` и
  формат часов; `document.title` и `<meta name="description">` обновляются в
  `applyLanguage()`.

## Формат времени

Настройка `settings.timeFormat`: `auto` | `24` | `12`.

- `auto` — 12 часов для английского, 24 для остальных;
- `formatTime(date)` — часы с минутами по текущей локали;
- `formatClock("06:30")` — то же для строки `HH:MM` из данных;
- `formatWindow(start, end)` — «06:30–09:30» или «6:30 AM–9:30 AM».

Нативные `<input type="time">` в редакторе подчиняются системе, а не этой
настройке — это ограничение браузера.

## RTL

`RTL_LOCALES = ["ar"]`. При переключении:

- `document.documentElement.dir = "rtl"`;
- сетка и списки зеркалятся автоматически (CSS grid/flex учитывают `dir`);
- флажки и галочки на плитке уезжают влево (`[dir="rtl"] .tile-flag`);
- стрелки направления получают класс `.flip` и отражаются (`scaleX(-1)`).

## Добавить язык

1. Скопируйте `js/core/dict/en.js` в `js/core/dict/<код>.js` и переведите
   значения. Ключи не менять.
2. Добавьте код в `LOCALES` и `LOCALE_NAMES` в `js/core/i18n.js`.
3. Добавьте код в `LANGS` в `js/core/state.js`.
4. Если язык RTL — добавьте его в `RTL_LOCALES`.
5. Добавьте файл в список кэша `sw.js` и поднимите `CACHE`.
6. `npm test` — тест сам скажет, каких ключей не хватает.
7. Создайте `README.<код>.md` по образцу `README.en.md`.

## Склонения

Ключ-объект выбирает форму через `Intl.PluralRules`:

```js
"tile.daysAgo": { one: "{n} день назад", few: "{n} дня назад", many: "{n} дней назад" }
```

У русского три формы, у английского две, у арабского шесть (`zero`, `one`,
`two`, `few`, `many`, `other`), у китайского одна (`other`). Если нужной формы
нет — берётся `other`.

## Что не переводится

- **Названия привычек пользователя.** Это данные, а не интерфейс.
- **Стартовый набор** переводится только при первом запуске — у нового
  пользователя привычки создаются на его языке.
- **Лицензия MIT** — юридический текст, не переводится.

## Ограничения

Язык переключается на клиенте, отдельного URL на язык нет. Поэтому hreflang не
используется: для поисковика страница одна, а `lang` меняется скриптом.

Переводы zh/hi/ar сделаны без носителя языка: корректны по смыслу, но перед
большой аудиторией нужна вычитка. Подробнее — `docs/LANGUAGES.md`.
