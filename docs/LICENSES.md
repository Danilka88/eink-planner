# Аудит лицензий и происхождения

Проверка: всё, что используется в проекте, имеет открытую лицензию, а чужие
права не нарушены. Дата проверки — 2026-11-10, версия 1.4.0.

## Состав проекта

| Что | Происхождение | Лицензия | Где указано |
|---|---|---|---|
| Код приложения (`js/`, `index.html`, `styles.css`, `sw.js`) | написано для проекта | MIT | `LICENSE` |
| Иконки, 40 шт. | Phosphor Icons 2.1.1, Bold | MIT | `THIRD-PARTY.md` |
| Шрифты | не используются, только системный стек | — | `THIRD-PARTY.md` |
| Скриншоты `design/screens/` | сняты с этого приложения | MIT (как часть проекта) | `LICENSE` |
| Дизайн-документы `design/*.md` | написаны для проекта | MIT | `LICENSE` |
| `design/` артефакты генератора | созданы локальным инструментом design-gate | не публикуются | `.gitignore` |

## Чего в проекте нет

- сторонних JS-библиотек и фреймворков;
- npm-зависимостей в рантайме (`package.json` без `dependencies`);
- веб-шрифтов, CDN, внешних стилей;
- аналитики, трекеров, пикселей;
- изображений из стоков или чужих галерей;
- кода под GPL/AGPL — а значит, нет и обязательств по раскрытию исходников
  связанных модулей.

## Проверка командой

```bash
# 1. Внешние адреса: должны остаться только schema.org, github и сам сайт
grep -rno "https\?://[a-zA-Z0-9./_-]*" js/ index.html styles.css sw.js \
  | grep -v "w3.org\|schema.org\|github.com\|danilka88.github.io"

# 2. Зависимости рантайма
node -e "const p=require('./package.json'); console.log(p.dependencies||'нет')"

# 3. Сетевые вызовы в приложении: только service worker за своими файлами
grep -rn "fetch(\|XMLHttpRequest\|sendBeacon\|WebSocket" js/ index.html

# 4. Лицензия иконок на месте
grep -c "MIT License" THIRD-PARTY.md
```

## Тексты и переводы

Что проверено:

- **Нейтральность.** Все строки — про привычки, время, данные и настройки. Нет
  упоминаний политики, религии, национальностей, здоровья в медицинском смысле,
  алкоголя, азартных игр. Названия стартовых привычек — бытовые (зубы, вода,
  витамины, разминка, дневник).
- **Нет обещаний и советов.** Приложение не даёт медицинских, финансовых или
  юридических рекомендаций. «Витамины» — просто название привычки, а не совет.
- **Нет персональных данных.** В репозитории нет почты, телефона, адреса и имён
  пользователей. Единственное имя — владелец репозитория в `LICENSE` и ссылках.
- **Нет чужих товарных знаков.** «Takt» — рабочее название проекта, не
  зарегистрированный знак; иконки и тексты оригинальные или под MIT.
- **Подстановки.** Автотест проверяет, что ни в одном языке не осталось
  незаполненных `{...}` и пустых строк (`tests/i18n.test.js`).
- **Склонения.** Проверяются `Intl.PluralRules` для всех 8 языков, включая
  шесть форм арабского.

Ограничение: переводы на китайский, хинди и арабский сделаны без носителя
языка. Они корректны по смыслу и нейтральны, но перед серьёзной аудиторией
стоит показать носителю. Это отмечено в `docs/LANGUAGES.md`.

## Соответствие требованиям магазинов и поиска

- Приложение не собирает данные — значит, нет требований GDPR/152-ФЗ по
  обработке персональных данных (данные не покидают устройство).
- Нет cookie, нет трекинга — баннер согласия не нужен.
- `PRIVACY.md` описывает хранение данных простым языком.
- Ссылка на исходный код и лицензия доступны из интерфейса (Настройки → О
  приложении).

## Как добавить чужой ресурс

1. Проверить лицензию: MIT/ISC/Apache-2.0/CC0 — можно; GPL/AGPL — нельзя без
   смены лицензии проекта.
2. Вписать в таблицу выше: что, откуда, версия, лицензия.
3. Полный текст лицензии — в `THIRD-PARTY.md`.
4. Если это шрифт или картинка — добавить файл лицензии рядом с ресурсом.
