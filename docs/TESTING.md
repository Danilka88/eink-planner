# Тесты и проверки

## Юнит-тесты

```bash
npm test
```

Проверяют то, что не видно глазами:

- окна привычек и переход через полночь;
- повтор: день / дни недели / число месяца (включая 31-е в феврале) / разово;
- `keepOverdue`: плитка остаётся или исчезает;
- время жизни выполненной плитки (`hideDoneMin`);
- долги: один на привычку, самый свежий, лимит `debtDays`;
- миграция v1 → v2;
- склонения во всех 8 языках и совпадение набора ключей между словарями;
- формат времени 12/24 ч;
- версия совпадает с `package.json`;
- все named-импорты существуют в целевых модулях (опечатка ловится без браузера);
- у каждого модуля `js/ui/*` есть потребитель;
- `SHELL` в `sw.js` покрывает все импорты и ресурсы `index.html` — иначе офлайн
  сломается ровно в самолёте.

Тесты гоняются в Node без браузера: ядро не трогает DOM, а тесты структуры
читают файлы как текст.

## Линтер

```bash
npm run lint
```

ESLint 9 с браузерными глобальными: `no-undef`, `no-unused-vars`, `no-var`,
`eqeqeq`, `prefer-const`, `no-shadow`. `node_modules` в рантайме нет — это
только dev-зависимость.

## code-gate

```bash
CG="$HOME/Documents/opencode/code-gate/scripts/cg.py"
PATH="$PWD/node_modules/.bin:$PATH" python3 "$CG" detect --path .   # что доступно
PATH="$PWD/node_modules/.bin:$PATH" python3 "$CG" sweep  --path .   # вердикт
PATH="$PWD/node_modules/.bin:$PATH" python3 "$CG" ratchet --path .  # запрет регресса
```

Вердикт `CLEAN` — открытых находок нет. `missing` у анализатора — это не
`pass`: отсутствие проверки попадает в отчёт отдельной строкой. Отчёты лежат
в `.code-gate/` и в git не попадают.

## Проверка в браузере

```bash
python3 -m http.server 8080
```

Открыть `http://127.0.0.1:8080` и пройти чек-лист:

1. Отметка плитки → инверсия, «Отменить» в полосе снизу.
2. Долгое нажатие → редактор; на просроченной → «пропустить».
3. «Все» → три вкладки, копирование, архив, возврат.
4. История: снять отметку, отметить, пропустить, вернуть.
5. Настройки: тема, язык, демо-сетка, экспорт и импорт.
6. Полный экран из настроек: окно не должно «просесть».
7. Офлайн: включить авиарежим и перезагрузить (только https или localhost).

## Аудит дизайна

```bash

python3 "$GATE/scripts/design_audit.py" . --live "http://127.0.0.1:8080/" --shots-dir design/screens
```

Ожидаемо: `errors 0`, `slop 0`.

### Доступность

Проверяется Lighthouse через Chrome DevTools MCP:

| Категория | Оценка |
|---|---|
| Accessibility | 100 |
| Best Practices | 100 |
| SEO | 100 |
| Agentic Browsing | 100 |

Важно: строгая CSP (`script-src 'self'`) не даёт внешним инструментам вроде
`axe-core` внедрить свой скрипт в страницу, поэтому `design_audit --live`
показывает `LIVE-02` («live metrics unavailable») — это ограничение
инструмента, а не дефект страницы. Доступность меряется Lighthouse.
