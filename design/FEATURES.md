# FEATURES — полный план функций

## v1.1 — добавлено по замечаниям

- **Исправлено:** иконки в кнопках рисовались чёрной заливкой — в тёмной теме
  это давало чёрный квадрат вместо кнопки. Символы спрайта теперь несут
  собственные `fill="none" stroke="currentColor"`, а сгенерированные иконки
  получают класс `.ic`.
- **Просрочка остаётся на экране.** После `end` плитка не исчезает, а
  становится серой с «!» и подписью «просрочено · до HH:MM», пока её не
  отметят или не пропустят. Чекбокс «Не убирать с экрана, пока не выполнено»
  в редакторе (по умолчанию включён); снятый — старое поведение «исчезает по
  окончании окна».
- **Повтор:** каждый день / по дням недели / каждое N-е число месяца / разово
  на дату. Тип повтора показан в списке привычек.
- **Копирование привычки:** кнопка «копировать» в списке и «Дублировать» в
  редакторе — создаёт копию со всеми полями.
- **История:** раздел «Все → История» — все дни по убыванию, статус каждой
  привычки (выполнено с временем / пропущено / не отмечено), действия «снять»,
  «отметить», «пропустить», «вернуть». По умолчанию 7 дней, кнопка «показать
  ещё» до 30.
- **Архив:** «Все → Архив» — выключенные привычки, «вернуть» (вся история
  сохраняется) и «удалить навсегда» (корзина, двойное нажатие). Удаление из
  редактора теперь мягкое: привычка уходит в архив, а не исчезает.

## Уже в v1.0 (этот проект)

### Доска дня
- Сетка крупных тайлов без прокрутки: 1–4 колонки в зависимости от числа и
  ориентации; последний нечётный тайл растягивается.
- Привычка появляется в окне `start–end`, исчезает после `end`.
- Состояния: ждёт / выполнено / пропущено / долг; пропуск виден без цвета.
- Долг за прошлые дни (по умолчанию 3 дня), один долг на привычку — самый
  свежий пропуск. Долги видны на доске после сегодняшних привычек и в разделе
  «Долги» списка «Все», где их можно закрыть задним числом или пропустить.
- Прогресс дня `3/6` + сегментная полоса.
- Часы, дата, день недели; «локально» когда нет сети.
- Пустое состояние: «Свободно» + следующая привычка и время.
- `+N ещё`, если привычек больше, чем влезает на экран.

### Отметки
- Касание — выполнено / снять.
- Долгое нажатие — редактор; на пропуске — «пропустить».
- Тост с «Отменить» после каждого действия.
- Отметка за прошлый день (долг) с пометкой `late`.
- Выполненные исчезают через 5/10/20/30/60 минут (настройка).

### Привычки
- Создание: название (40 символов), иконка (22 варианта), окно времени, дни
  недели.
- Редактирование, удаление с подтверждением, включение/выключение без потери
  истории.
- Сортировка по времени; группировка «Утро / День / Вечер» в списке.
- Шаблон при первом запуске: зубы утром/вечером, витамины, вода, разминка,
  дневник.

### Данные и офлайн
- `localStorage`, версия схемы, миграция и валидация импорта.
- Экспорт JSON, импорт JSON, сброс с двойным подтверждением.
- `navigator.storage.persist()` — просьба не вытеснять данные.
- Service worker: кэш оболочки, работа без сети после первого запуска.
- PWA-манифест: fullscreen, иконки 192/512, SVG.

### E-ink и энергия
- 1-битная палитра, без градиентов/теней/blur, радиус 0–2 px.
- Ноль анимаций; `data-eink` и `prefers-reduced-motion` отключают всё.
- Полное обновление экрана: кнопка + авто 0/15/30/60 минут.
- Wake lock (если поддерживается), пауза таймера при скрытой вкладке.
- Один интервал 15 с; перерисовка только при смене подписи состояния.

### Доступность
- Нативные кнопки/диалог/поля, один h1, landmarks, `aria-pressed`,
  `role=progressbar`, фокус 5 px, цели ≥ 50 px, обе темы AA.

## v1.1 — следующий шаг (2–4 недели)

1. **Серии и статистика**: текущая серия, лучшая серия, % за 7/30 дней.
   Отдельный экран «Статистика» с 1-битной тепловой картой (7×N), без прокрутки
   на главном.
2. **Экран недели**: сетка 7 дней × привычки, отметки задним числом.
3. **Количество**: «Вода 500 мл × 4» — тап добавляет порцию, цель показывается
   сегментами.
4. **Заметка к отметке**: короткий текст/причина пропуска (локально).
5. **Шаблоны**: наборы привычек («Утро», «Спорт», «Командировка»), применение
   одним действием.
6. **Дублирование и перестановка** привычек кнопками (без drag-and-drop).
7. **Напоминание об экспорте** раз в 30 дней и перед сбросом.
8. **Онбординг**: 3 карточки при первом запуске (касание, долгое нажатие, все).
9. **CSV-экспорт** для таблиц.
10. **Проверка свободного места** и предупреждение при `QuotaExceededError`.

## v2 — если появится Android-обёртка

- Виджет на главный экран (App Widget / Glance) с 3–5 привычками.
- Локальные уведомления в окне времени (WorkManager), без сети.
- Быстрые настройки (Quick Settings tile) «отметить воду».
- Синхронизация через файл/WebDAV — только по явному запросу, по умолчанию нет.
- Несколько профилей (утро/вечер, будни/выходные) с разными досками.

## Что сознательно не делаем

- Аккаунты, облако, соцфункции, рейтинги.
- Push-уведомления в чистом вебе: без сети и фонового процесса невозможны.
- Анимации, конфетти, звуки: против e-ink и батареи.
- Бесконечная лента и прокрутка главного экрана.
- Цвет как единственный носитель состояния.

## Критерии готовности следующей версии

- Главный экран по-прежнему без прокрутки на 536×724 и 724×536.
- Любая новая функция не добавляет сетевых запросов.
- `design_audit` — 0 errors, axe 0, slop ≤ 1.
- Экспорт/импорт покрывает новые поля и старые файлы.
