# RESEARCH — аналоги, e-ink и выводы

Живой веб-поиск в этой сессии не отвечал (таймауты), поэтому ниже — разбор
известных продуктов по их публичному поведению и документированным
ограничениям e-ink. Это не цитаты и не маркетинговые обещания; спорные пункты
помечены как гипотезы.

## 1. Аналоги

### Loop Habit Tracker (Android, open source)
- Локальная БД, без аккаунта; привычка = имя + иконка + частота; серии и графики.
- Сильная сторона: офлайн и честная статистика.
- Слабость для нашей задачи: список с прокруткой, мелкие элементы, нет
  «появилась в окне времени».
- Берём: локальность, одна привычка = одна цель, серия как мотивация (v1.1).

### Streaks (iOS)
- До 12 привычек, крупные цветные плитки, отметка касанием, виджет.
- Сильная сторона: одно действие, минимум трения.
- Слабость: цвет и анимация — против e-ink; нет окон времени.
- Берём: «касание = готово», ограничение набора, виджет-идею (Android-виджет
  вне веба, v2).

### Habitica (веб/мобайл)
- Геймификация, партия, награды; онлайн-аккаунт.
- Не подходит: сеть, аккаунт, визуальный шум.

### Tiimo (визуальный планер)
- Временные блоки, крупные иконки, поддержка нейроразнообразия.
- Берём: окно времени как единица, а не «строка в списке».
- Не берём: таймлайн с прокруткой и мелкой сеткой.

### TRMNL / e-ink dashboards
- Сервер рендерит статичный кадр, устройство раз в N минут забирает картинку.
- Сильная сторона: минимум обновлений, 1-битная графика, батарея.
- Слабость: нужен сервер и сеть; интерактивность ограничена.
- Берём: статичный кадр, редкое обновление, крупные зоны, полное обновление
  для очистки ghosting.

### Бумажный чек-лист
- Видно всё, одно действие ручкой, нет питания.
- Слабость: нет времени, нет памяти о пропусках, нельзя перестроить.
- Берём: «всё на одном экране», физическая крупность.

### Заметки на e-ink (Boox/Kobo)
- Встроенные заметки и календарь; рукописный ввод, но список и меню мелкие.
- Вывод: веб-приложение должно само ограничивать плотность, а не надеяться на
  системный масштаб.

## 2. Ограничения e-ink, которые влияют на дизайн

| Ограничение | Следствие в UI |
|---|---|
| 16 градаций, часто 1 бит | только чёрный/белый + 2–3 серых; никаких полутонов в состояниях |
| Полное обновление 0.3–2 с, частичное с ghosting | нет анимаций; минимум изменённых пикселей; кнопка полной очистки |
| Нет сглаживания мелкого текста | минимум 15–16 px, лучше 20+; без тонких шрифтов |
| Медленный отклик | одно касание = одно действие; никаких двойных тапов и свайпов |
| Нет hover | состояния только default/pressed/focus; подсказки не на hover |
| Батарея | без сети, без rAF, редкий таймер, статичный кадр |
| Блики/угол обзора | высокий контраст, толстые линии, крупные цели |
| Нет фоновых уведомлений в вебе | «напоминание» = появление тайла в окне времени |

## 3. Гипотезы, которые проверит устройство

1. Частичное обновление Chrome на Android e-ink может инвертировать крупные
   области при смене тайла; поэтому есть ручная кнопка полного обновления.
2. Частота 30 минут для полной очистки — компромисс; настройка 0/15/30/60.
3. 2 колонки в портрете на 6" читаются лучше 3; проверено на 536×724.
4. `wakeLock` может быть недоступен в полноэкранном PWA на прошивке — тогда
   настройка «Не гасить экран» просто не сработает, без ошибки.

## 4. Что это меняет в продукте

- Главный экран — **доска**, не список.
- Пропуск — **отдельное состояние**, не «пустая галочка».
- Настройки — редко; всё управление привычками — в одном списке.
- Никакой сети вообще: ни шрифтов, ни аналитики, ни картинок.
- Экспорт JSON — обязательная страховка от очистки браузера.
