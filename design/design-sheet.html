Style

Swiss / editorial DS-STYLE

Направление: swiss grid / editorial

Берём

  • 12-колоночная сетка
  • сильная типографическая шкала
  • линейки
  • асимметрия

Адаптируем

  • Helvetica → Inter/Onest
  • печатные поля → адаптивные
  • ч/б → токены с AA

Не переносим

  • центрирование всего
  • декоративная антиква в теле
  • серый текст ниже 4.5:1

Agent surface

WebMCP tools

Экспериментальный слой (origin trial): инструменты повторяют действия UI, необратимые помечены и требуют подтверждения, лимиты — 30/500/150/1500 символов.

search_catalogSCR-LIST-01

Ищет элементы каталога по текстовому запросу. Возвращает название, цену и ссылку.

read-only · untrusted content · подтверждение: none

filter_catalogSCR-LIST-01

Оставляет в каталоге элементы выбранного типа (лес, вода, горы, город).

read-only · untrusted content · подтверждение: none

get_itemSCR-DETAIL-01

Возвращает описание, цену и доступные даты выбранного элемента.

read-only · untrusted content · подтверждение: none

compare_itemsSCR-COMPARE-01

Строит таблицу сравнения для двух–четырёх элементов по их идентификаторам.

read-only · untrusted content · подтверждение: none

get_order_summarySCR-CHECKOUT-01

Возвращает позиции, скидку и итоговую сумму текущего заказа.

read-only · untrusted content · подтверждение: none

apply_promoSCR-CHECKOUT-01

Применяет промокод к заказу и возвращает новую сумму или причину отказа.

neutral · подтверждение: inline

place_orderSCR-CHECKOUT-01

Создаёт заказ и списывает оплату. Необратимо, требует подтверждения пользователя.

consequential · подтверждение: dialog

get_order_statusSCR-ORDERS-01

Возвращает статус и дату доставки по номеру заказа.

read-only · untrusted content · подтверждение: none

get_profileSCR-ACCOUNT-01

Возвращает имя, почту и настройки текущего пользователя.

read-only · untrusted content · подтверждение: none

update_profileSCR-ACCOUNT-01

Сохраняет имя и почту пользователя. Изменение обратимо, подтверждение не требуется.

untrusted content · подтверждение: inline

set_themeSCR-SETTINGS-01

Переключает тему оформления: системная, светлая или тёмная.

neutral · подтверждение: none

get_sales_summarySCR-DASHBOARD-01

read-only · подтверждение: none

search_ordersSCR-ORDERS-01

Ищет заявки по имени клиента, туру или номеру и возвращает подходящие.

read-only · untrusted content · подтверждение: none

filter_ordersSCR-ORDERS-01

Оставляет заявки с выбранным статусом: новые, оплачены, ожидают или отменены.

Icons

Material Symbols DS-ICONS-SET-01

Один набор на проект. Variable-оси: FILL для активного состояния, wght/opsz для размера. Иконка наследует currentColor и работает в обеих темах.

20 24 32

Состояние: контур → заполненный. Icon-only кнопка обязана иметь aria-label; цель ≥44 px.

Emoji

Fluent Emoji DS-EMOJI-SET-01

3D — иллюстрации и онбординг, Flat — рядом с текстом. Только картинки, не системный шрифт: иначе Apple, Windows и Android нарисуют по-разному. Внутри контролов эмодзи не используем.
