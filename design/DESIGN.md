# DESIGN — РИТУАЛ, локальный планер привычек для e-ink

**Задача:** офлайн-сайт для 6-дюймового Android e-ink планшета: сетка привычек,
элементы появляются в своё время, отмечаются одним касанием, пропуски видны,
ничего не нужно прокручивать, читается с 1–2 метров.

**Стиль:** `swiss-editorial` (модульная сетка, крупная типографика, линейки,
ноль декора). **Платформа:** web / PWA, Android Chrome, fullscreen.
**Локаль:** ru. **Домен:** нет — приложение локальное, `noindex`.

---

## 1. Что исследовано

Живой веб-поиск в этой сессии был недоступен (таймауты), поэтому выводы ниже —
из известных продуктов и документированных ограничений e-ink, без выдуманных
цитат. Полная таблица — `design/RESEARCH.md`.

| Класс | Примеры | Что берём | Что не берём |
|---|---|---|---|
| Трекеры привычек | Loop Habit Tracker, Streaks | одна привычка = одна крупная цель; серия; локальные данные | графики и статистика на первом экране |
| Визуальные планеры | Tiimo | время как окно, а не список | таймлайн с прокруткой |
| E-ink панели | TRMNL, Kobo/Boox | 1-битная графика, редкое обновление, статичный кадр | серверная генерация, Wi-Fi |
| Бумага | чек-лист на холодильнике | «видно всё сразу», одно действие | нет времени и памяти о пропусках |

**Вывод:** это не дашборд и не календарь. Это **одноэкранная доска дня**, где
привычка сама появляется в окне времени, одно касание меняет её состояние, а
пропуск остаётся видимым, пока его не закрыть.

## 2. Ограничения e-ink (законы, не пожелания)

1. **1 бит безопаснее 16 градаций.** Палитра — чистый чёрный/белый и три
   служебных серых, каждый проходит AA. Никаких полупрозрачностей.
2. **Нет градиентов, теней, blur, скруглений > 2 px.** Они дают грязь при
   частичном обновлении.
3. **Нет анимаций.** Переходы 0 ms; состояние меняется мгновенно. Это же
   экономит батарею и убирает ghosting.
4. **Меняется минимум пикселей.** Часы обновляются раз в минуту; доска
   перерисовывается только при смене набора/состояний (подпись состояния).
5. **Полное обновление — по кнопке и по таймеру.** Белая/чёрная вспышка
   очищает остаточное изображение; по умолчанию раз в 30 минут.
6. **Крупные цели.** Минимум 44 px, фактически 54–72 px; тайл — вся площадь.
7. **Без прокрутки.** `body { overflow: hidden }`, сетка заполняет экран.
8. **Без сети.** Нет шрифтов с CDN, нет аналитики, нет запросов. Всё в
   `localStorage`, service worker кэширует оболочку.
9. **Энергия.** Один интервал 15 с, без `requestAnimationFrame`, без
   бесконечных циклов; при скрытой вкладке работа замирает.

## 3. Экран и сетка

Один экран, три зоны:

```
┌──────────────────────────────────────────┐
│ дата · прогресс 3/6 · часы 07:42         │  header, 3px линейка
├──────────────────────────────────────────┤
│  ┌────────┐ ┌────────┐ ┌────────┐        │
│  │ тайл   │ │ тайл   │ │ тайл   │        │  board: 1fr, без скролла
│  └────────┘ └────────┘ └────────┘        │
├──────────────────────────────────────────┤
│ + Добавить  Все  Обновить  Настройки     │  dock, 4 цели
└──────────────────────────────────────────┘
```

- Портрет: 1–2 колонки при 1–6 элементах, 3 при 7–9, 4 при 10+.
- Ландшафт: 1–9 → 3 колонки, 10–12 → 4.
- Больше 9 (портрет) / 12 (ландшафт) — девятый тайл `+N ещё` открывает список.
- Один элемент — на всю ширину; два — по половине; последний нечётный тайл
  растягивается на две колонки.
- Высота строк = `1fr`: сетка всегда вписывается в экран.

### Состояния тайла

| Состояние | Вид | Смысл |
|---|---|---|
| `pending` | белый, рамка 3px, иконка + название + окно | окно открыто, ждёт |
| `done` | инверсия: чёрный фон, белый текст, галочка | отмечено; исчезает через N минут |
| `missed` | серый фон, рамка 5px, «!», подпись «пропущено» | окно закрылось без отметки |
| `debt` | серый фон, двойная рамка, «!», «вчера / N дн. назад» | пропуск прошлого дня |
| `upcoming` | не показывается | окно ещё не открылось |

Пропуск нельзя «потерять»: он либо на доске, либо в разделе «Долги» списка
«Все», пока не отмечен поздно или не пропущен осознанно. Если элементов больше,
чем влезает, девятый тайл `+N ещё` открывает список; сегодняшние привычки всегда
стоят раньше долгов.

## 4. Взаимодействие

- **Касание тайла** — отметить / снять отметку. Одно действие, без меню.
- **Долгое нажатие (650 мс)** — редактор привычки; на пропущенном — «пропустить».
- **Кнопка «Все»** — список: включить/выключить, изменить, удалить, добавить.
- **Настройки** — тема, частота полного обновления, сколько держать выполненные,
  глубина долгов, wake lock, экспорт/импорт, сброс.
- **Отмена** — тост с кнопкой «Отменить» после каждой отметки.
- **Клавиатура** — тайлы это `<button>`, Enter/Space работают; фокус-обводка 5px.

### Логика дня

- День календарный, с 00:00.
- Окно привычки: `start`–`end`; если `end <= start`, окно переходит через
  полночь.
- `now < start` — скрыто; `start <= now < end` — `pending`; `now >= end` —
  `missed` (кроме привычки, созданной сегодня: она не считается пропущенной).
- Выполненные видны `hideDoneMin` (по умолчанию 20 минут), затем исчезают.
- Долг: для каждой привычки берётся **самый свежий** пропущенный день в пределах
  `debtDays` (по умолчанию 3), не все дни подряд. Привычка, отмеченная сегодня,
  долг не показывает.
- Новая привычка, созданная после своего окна, не становится пропуском в тот же
  день.

## 7. Доступность

- Один `<h1>` (sr-only), `<main>`, `<header>`, `<footer>`, нативный `<dialog>`.
- Все цели ≥ 44×44; фактически ≥ 50 px; тайл — вся площадь.
- `aria-pressed` на тайле и переключателях, `aria-label` с названием и состоянием.
- Прогресс — `role=progressbar` + текстовое `3/6` + `aria-valuetext`.
- Фокус: 5 px `outline` с offset 2; `:focus-visible` для всех контролов.
- Обе темы проверены axe (WCAG 2.2 AA), 0 нарушений.
- `prefers-reduced-motion` и `data-eink` отключают любые переходы.
- Нет текста, который несёт смысл только цветом: пропуск = серый фон + «!» +
  слово «пропущено».

---

## 8. Осознанно не делаем

- Не тащим React/шрифты/CDN: офлайн и батарея важнее.
- Не делаем графики и серии на главном экране: это отдельный режим v1.1.
- Не используем push-уведомления: без сети и без фонового процесса они
  невозможны; роль напоминания играет появление тайла.
- Не делаем аккаунт, синхронизацию, сервер.
- Не переносим `robots.txt`/`sitemap.xml`: страница `noindex`, домена нет.
