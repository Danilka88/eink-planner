# Takt — ई-इंक के लिए आदत प्लानर

6 इंच ई-इंक टैबलेट के लिए एक-पृष्ठ, लोकल ऐप। बड़ी टाइलें, स्क्रॉल की ज़रूरत
नहीं, एक स्पर्श में चिह्न, बकाया बंद होने तक दिखता रहता है। नेटवर्क नहीं,
खाता नहीं, एनालिटिक्स नहीं: डेटा डिवाइस के ब्राउज़र में रहता है।

**लाइव:** https://danilka88.github.io/eink-planner/

![बोर्ड](design/screens/eink-536-day.png)

## क्या करता है

- **दिन का बोर्ड।** 1–4 कॉलम, टाइलें पूरी स्क्रीन भरती हैं, 1–2 मीटर से पढ़ी जा सकती हैं।
- **आदत अपनी खिड़की में।** `06:30` पर दिखती है, `09:30` के बाद
  «बकाया · {end} तक» बन जाती है और चिह्नित होने तक रहती है (बंद किया जा सकता है)।
- **एक स्पर्श** — पूरा: टाइल उलट जाती है, 5–60 मिनट बाद हट जाती है।
- **दोहराव:** हर दिन, सप्ताह के दिन, महीने का दिन, एक बार।
- **इतिहास और संग्रह।** हर दिन के चिह्न, हटाना और बहाल करना; बंद आदतें इतिहास रखती हैं।
- **डुप्लिकेट** एक स्पर्श में।
- **बकाया** पिछले दिनों से, बाद में बंद किए जा सकते हैं।
- **8 भाषाएँ**, हल्की/गहरी/ऑटो थीम, JSON निर्यात और आयात।
- **ऑफ़लाइन:** service worker, PWA मैनिफ़ेस्ट, शून्य नेटवर्क अनुरोध।

## शुरुआत

```bash
git clone https://github.com/Danilka88/eink-planner.git
cd eink-planner
python3 -m http.server 8080
```

`http://127.0.0.1:8080` खोलें।

> `index.html` डबल-क्लिक से नहीं खुलेगा: ऐप ES मॉड्यूल इस्तेमाल करता है और
> ब्राउज़र `file://` पर उन्हें रोकता है।

### टैबलेट पर इंस्टॉल

1. साइट **https** (या `localhost`) पर खोलें — ऑफ़लाइन कैश सिर्फ़ वहीं चलता है।
2. ब्राउज़र मेन्यू → «होम स्क्रीन पर जोड़ें»।
3. एयरप्लेन मोड चालू करें और शॉर्टकट खोलें: बिना नेटवर्क काम करता है।

सामान्य `http://192.168.x.x` पर ऑफ़लाइन मोड नहीं है — यह ब्राउज़र की सीमा है,
ऐप की गड़बड़ नहीं। सेटिंग्स → ऐप के बारे में स्थिति दिखाता है।

## नियंत्रण

| क्रिया | क्या करता है |
|---|---|
| टाइल दबाएँ | चिह्नित / हटाएँ |
| देर तक दबाएँ | आदत संपादक |
| बकाया टाइल देर तक दबाएँ | छोड़ना दर्ज करें |
| «सभी» → «आदतें» | चालू/बंद, डुप्लिकेट, संपादन, जोड़ें |
| «सभी» → «इतिहास» | दिन के अनुसार: हटाएँ, चिह्नित, छोड़ें, बहाल |
| «सभी» → «संग्रह» | बहाल करें या हमेशा के लिए मिटाएँ |
| «रीफ़्रेश» | पूरी स्क्रीन फ़्लैश (भूत साफ़ करना) |
| «सेटिंग्स» | थीम, भाषा, समय प्रारूप, टाइमर, डेमो, निर्यात |

## निजता

कोई नेटवर्क अनुरोध नहीं: CSP में `connect-src 'self'` ब्राउज़र स्तर पर रोकता है,
और ऐप खुद कोई नहीं करता। डेटा `localStorage` में रहता है और डिवाइस नहीं छोड़ता।
देखें `PRIVACY.md`।

## डेटा

- सब कुछ डिवाइस के ब्राउज़र के `localStorage` में रहता है। कोई सिंक नहीं।
- **«साझा करें»** एंड्रॉइड का मेन्यू खोलता है: फ़ाइल सीधे Telegram, मेल या Files में जाती है।
- **«फ़ाइल में निर्यात»** `takt-YYYY-MM-DD.json` डाउनलोड करता है।
- **«फ़ाइल से आयात»** पुष्टि के बाद सब कुछ बदल देता है।
- साइट डेटा साफ़ करने पर आदतें चली जाती हैं: निर्यात ही एकमात्र सुरक्षा है।
- पता = स्टोरेज। पता बदलने पर डेटा निर्यात और आयात से ले जाएँ।
